# MundoFlag mobile app (App Store + Google Play)

A [Capacitor](https://capacitorjs.com) shell around the live MundoFlag site: the app opens
`server.url` from `capacitor.config.json` full screen, so every game update deployed to the
server reaches the app immediately — a new store release is only needed for changes in this folder.

## Before the first build
1. **Domain** — the app needs the site on **HTTPS** with a real domain (iOS refuses plain HTTP).
   Put it in two places:
   - `capacitor.config.json` → `server.url`
   - `www/offline.html` → `SITE`
2. **App id** — `com.mundoflag.app` (`capacitor.config.json` → `appId`). It becomes permanent
   once the app is published in either store, so change it now if you want a different one.

## Commands (run inside `mobile-app/`)
```bash
npm install          # once
npx cap sync         # after changing capacitor.config.json or plugins
npm run icons        # after replacing assets/icon-only.png / splash.png
npx cap open android # opens Android Studio  -> build / run / "Generate Signed Bundle"
npx cap open ios     # opens Xcode (Mac only) -> run on a device / Product > Archive
```

## What's in here
| Path | What it is |
|---|---|
| `capacitor.config.json` | App name, id, site address, splash screen, system bars |
| `www/offline.html` | Shown when the server can't be reached (no internet / server down) |
| `assets/` | Source images for the icon and splash screen (placeholders — replace with your design, 1024×1024 icon, 2732×2732 splash) |
| `android/`, `ios/` | The native projects (generated by Capacitor; normally only touched for version numbers, signing and store settings) |

Version numbers for each store upload: Android `android/app/build.gradle` (`versionCode` +1 every
upload, `versionName`), iOS in Xcode (Version / Build).

## Behaviour wired up in the site itself (`src/main/resources/static/js/mobile.js`)
- Android back button goes back a page; on the home page it leaves the app.
- `<html class="is-native-app">` when running inside the app (for app-only styling).
